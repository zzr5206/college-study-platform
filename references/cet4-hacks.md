# 四级邪修技巧 — 看不懂听不懂也能捞分

> ⚠️ 以下技巧是考场救命稻草，不能替代扎实复习。建议先正常做，实在不会再用这些招。

---

## 🎧 听力邪修

### 最核心三条

**1. 听到什么选什么**
四级听力 80% 是原词复现，哪个选项被读到的单词最多就选哪个。别想太多。

**2. 女神永远是对的**
男女对话中，女生说的观点、建议、判断 = 答案。男生邀请女生 → 女生拒绝（but I'd love to...）。教授的课一定难，作业一定多。

**3. 转折词后面 = 答案**
but / however / actually / in fact / yet 后面那句，90% 出答案。

### 选项规律

| 规律 | 操作 |
|------|------|
| 两个选项意思相反 | 答案必在二者之间 |
| 两个选项意思相近 | 都不选 |
| 有 might/could/likely | 优先选 |
| 有 must/never/all | 慎选（大概率错） |
| 相邻两题 | 几乎不会选同一个选项（AA/BB/CC/DD 概率极低） |

### 实在听不懂时

- 选最正能量、最符合常识的（早睡早起、努力学习、保护环境）
- 开头两句和最后两句必出 1-2 题
- 听到数字就记下来，题目必考一个数字
- **边听边涂答题卡！听力结束立即收卷，没时间补涂**

## 📖 阅读邪修

### 仔细阅读 — 看不懂也能对

**黄金法则：may 字诀**
> 选项中只要出现 may / might / possible / likely / some，**直接选**。含绝对词 must / never / all / only / completely 的，**直接排除**。这条规则正确率 85%+。

**同义替换 = 正确答案**
> 和原文用词完全一样的选项 → 陷阱。换个说法表达同一意思的 → 答案。

**答案分布均匀**
> ABCD 四个选项数量大致相同。如果你已经选了 3 个 A 但一个 D 都没选，后面优先蒙 D。

**顺序原则**
> 题目顺序 = 原文段落顺序。第 1 题在前面找，最后一题在末尾找。

### 长篇匹配 — 10 分钟搞定

1. 先看 10 个题干，各圈 2-3 个关键词
2. 扫读原文段落首末句（不要逐句读！）
3. 关键词匹配 ≥2 个 → 就是这段
4. 找不到就优先选段落首尾句有同义替换的

### 选词填空 — 性价比最低，最后做

1. 先给 15 个选项标词性（n./v./adj./adv.）
2. 根据空前后的语法信号判断要什么词性
3. 从符合词性的 2-3 个候选中挑顺眼的
4. -ing/-ed 结尾的优先考虑
5. 做不完就全蒙 C

### 选项排除四式

| 招式 | 判断 | 操作 |
|------|------|------|
| 无中生有 | 选项信息原文完全没提 | 直接排除 |
| 偷换概念 | some→all, may→must, A→B | 排除 |
| 答非所问 | 选项本身正确但不回答题干 | 排除 |
| 过度推理 | 原文"A有助于B"，选项"A是B唯一原因" | 排除 |

## ✍️ 写作邪修

### 万能模板（背下来就有 80 分）

```
第一段：Nowadays, [抄题目话题] has become increasingly popular.
        Different people have different views on this issue.

第二段：Those in favor argue that [正面理由1]. Moreover, [正面理由2].
        However, others point out that [反面理由1].
        As far as I'm concerned, both sides have their merits.

第三段：In conclusion, [换个说法复述观点].
        Only in this way can we [展望未来].
```

### 救命词汇升级（立刻提一档分）

| 别写 | 换成 |
|------|------|
| good | beneficial / favorable |
| bad | harmful / detrimental |
| important | significant / crucial / vital |
| many | numerous / a variety of |
| help | contribute to / be conducive to |
| I think | From my perspective |
| more and more | an increasing number of |

### 底线

- 字数 120-180，**写满答题卡一面刚好**
- 字迹工整比内容重要（阅卷老师 30 秒一篇作文）
- 绝不要出现明显拼写错误（不确定的词就别用）
- 连接词必须有：First, Moreover, In conclusion

## 🌐 翻译邪修

### 核心大法：不会的词用解释法

| 不会写 | 解释着写 |
|--------|---------|
| 故宫 | the old palace in Beijing |
| 红包 | red envelopes with money inside |
| 四合院 | traditional Chinese house with a courtyard |
| 春运 | the travel rush during the Spring Festival |

### 长句拆短（保命技巧）

中文一句话逗号串到尾 → 英文拆成 2-3 句简单句。
> "随着经济发展，人民生活水平不断提高"  
> → "The economy is developing. People's lives are getting better."

### 无主语句 → 被动

> "应该采取措施保护环境"  
> → "Measures should be taken to protect the environment."

### 翻译实在不会的词就跳过

翻译是扣分制，漏一个词只扣 0.5，写错一个词扣 1 分。不会的词宁愿跳过别瞎写。

2. 扫一遍救命词汇升级表
3. 听听力前把 Section A 选项全部预读一遍
4. 深呼吸，425 就及格，做对 60% 就过
