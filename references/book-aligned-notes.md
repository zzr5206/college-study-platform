# 按教材对齐的复习补充

说明：
- 下面内容按公开可检索的教材信息、课程大纲和常见本科考题整理。
- 练习题是同型题和仿题，不逐字复现原书课后题。

## 1. 韩士安版抽象代数

### 重点顺序

1. 群的基本概念
   - 群、子群、循环群、元素的阶
   - 陪集、拉格朗日定理
2. 同态与正规结构
   - 群同态、核、像
   - 正规子群、商群、第一同构定理
3. 环与理想
   - 环、交换环、整环、域
   - 理想、商环、极大理想、素理想
4. 后续进阶
   - 多项式环、不可约性、有限域
   - 伽罗瓦理论入门

### 重点判断题

- 子群判别：先证非空，再证 `ab^{-1}` 封闭。
- 正规子群：看共轭是否封闭，或直接用核。
- 商群/商环：先看正规子群或理想。
- 域判断：重点看非零元是否都可逆。
- \(\mathbb Z_n\) 中单位元判断：看 `gcd(a,n)=1`。

### 代表性习题

1. 证明 `C_G(a)` 是子群。
   - 思路：用共轭或 `ab^{-1}` 判别。

2. 证明群同态的核是正规子群。
   - 思路：`phi(gkg^{-1}) = e`。

3. 判断 `Z_12` 中哪些元素可逆。
   - 答案：`[1],[5],[7],[11]`。

4. 证明交换环中的任意子群不一定是理想。
   - 思路：给出加法子群但不吸收乘法的反例。

5. 证明极大理想对应商环是域。
   - 思路：用极大性排除真理想。

6. 证明拉格朗日定理推出元素阶整除群阶。
   - 思路：看元素生成的循环子群。

### 课后题风格提醒

- 很多题要求“证明某集合是子群/理想”，最核心的是判别法。
- 证明题常先把题目改写成定义语言，再逐条验证。
- 计算题常考有限群、循环群、`Zn`、置换群、商群。

## 2. 余家荣版复变函数

### 重点顺序

1. 复数与复函数
   - 复数运算、极限、连续、可导
   - 解析函数、C-R 方程
2. 积分与定理
   - 复积分、原函数
   - Cauchy 积分定理、Cauchy 积分公式
3. 展开与奇点
   - Taylor 级数、Laurent 级数
   - 可去奇点、极点、本性奇点
4. 留数与应用
   - 留数计算
   - 围道积分与实积分

### 重点判断题

- 是否解析：先验 C-R 方程，再看偏导连续性。
- 是否可去奇点：看 Laurent 展开是否有负幂。
- 是否极点：负幂是否只有有限项。
- 是否能直接用 Cauchy 公式：先看奇点是否在曲线内。

### 代表性习题

1. 判断 `f(z)=conj(z)^2` 的解析性。
   - 答案：仅在原点满足 C-R，但不在任何邻域解析。

2. 计算 `\int_|z|=2 e^z/(z-1) dz`。
   - 答案：`2 pi i e`。

3. 求 `1/(z(z-1))` 在环域中的 Laurent 展开。
   - 思路：分别在 `|z|<1` 和 `|z|>1` 改写成几何级数。

4. 分类奇点 `f(z)=1/(z^2(z-1))` 在 `z=0` 处的类型。
   - 答案：二阶极点。

5. 计算 `Res((z+1)/(z(z-1)), 0)`。
   - 答案：`-1`。

6. 说明解析函数在区域内恒等于零的条件。
   - 思路：用恒等定理。

### 课后题风格提醒

- 大题经常围绕“判断解析性-求积分-求展开-算留数”四条线展开。
- 很多题只要看出公式入口，剩下是代数计算。
- 练习时一定要把“区域、闭路方向、奇点位置”写清楚。

## 3. 清华版运筹学

### 重点顺序

1. 线性规划建模
   - 变量、目标函数、约束
   - 标准型、可行解、最优解
2. 单纯形法
   - 初始基、检验数、主元、入基出基
   - 退化、无穷多解、无界、不可行
3. 对偶理论
   - 原问题与对偶问题
   - 弱对偶、强对偶、互补松弛
4. 专题模型
   - 运输问题、指派问题
   - 整数规划、动态规划
   - 图上的最短路、最小生成树、最大流

### 重点判断题

- 建模题：先找决策变量，再写目标和约束。
- 单纯形题：重点看入基列、出基行和检验数。
- 对偶题：重点看符号、方向和变量个数对应。
- 运输题：是否平衡，是否需要虚拟行/列。
- 动规题：阶段、状态、决策、转移、边界五件套。

### 代表性习题

1. 建模：利润最大化问题。
   - 设变量，写目标函数和资源约束。

2. 写出原问题的对偶。
   - 思路：行列对应、最大变最小、`<=` 常转 `>=`。

3. 判断一个给定解是否最优。
   - 思路：看检验数和可行性。

4. 运输问题中为什么要 `m+n-1` 个基变量。
   - 答案：与基本可行解的维数对应。

5. 指派问题为什么可以用匈牙利法。
   - 思路：它是特殊的 0-1 线性规划。

6. 说明动态规划建模的四要素。
   - 答案：阶段、状态、决策、状态转移。

### 课后题风格提醒

- 计算题和应用题占比高。
- 容易丢分的地方是符号、单位和“谁是行谁是列”。
- 运输和指派题通常先做化标准，再做表格运算。

## 4. 严蔚敏版数据结构

### 重点顺序

1. 线性表
   - 顺序表、链表
   - 插入、删除、查找
2. 栈和队列
   - 顺序栈、链栈、循环队列
   - 括号匹配、表达式求值、BFS
3. 树与二叉树
   - 遍历、二叉搜索树、堆
   - 递归和层序遍历
4. 图
   - 邻接矩阵、邻接表
   - DFS、BFS、最短路、最小生成树
5. 查找与排序
   - 二分查找、哈希查找
   - 冒泡、插入、选择、快速、归并、堆排序

### 重点判断题

- 顺序表：查找快，插删慢。
- 单链表：插删快，但不能随机访问。
- 队列：BFS 的基础。
- 二叉搜索树：中序遍历有序。
- 哈希表：重点是冲突处理。
- 排序题：常考稳定性和复杂度。

### 代表性习题

1. 写单链表删除值为 `x` 的结点代码。
   - 思路：先找前驱，再改链，再 `free`。

2. 写循环队列判空判满条件。
   - 答案：`front == rear`，`(rear + 1) % MAXSIZE == front`。

3. 说明为什么中序遍历 BST 得到有序序列。
   - 思路：左小根右大的递归定义。

4. 比较 `O(n)`、`O(log n)`、`O(n log n)`、`O(n^2)` 的常见算法。
   - 重点：查找、树、排序、图。

5. 说明插入排序稳定、快速排序通常不稳定。
   - 思路：是否会跨越交换相同关键字。

6. 手写 DFS 和 BFS 的基本框架。
   - 思路：DFS 用递归/栈，BFS 用队列。

### 课后题风格提醒

- 代码题常考指针和边界情况。
- 图和树题常考遍历过程、生成树和最短路。
- 排序题通常要会手算一到两轮过程。

- 抽象代数：增加伽罗瓦理论和有限域小题。

- 数据结构：增加树、图、哈希和排序专项代码题。
