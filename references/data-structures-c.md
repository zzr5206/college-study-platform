# 数据结构 C 语言版期末复习

## 复习核心

数据结构考试常见题型：
- 概念和复杂度选择题。
- 手写基本操作代码。
- 画执行过程。
- 分析算法时间复杂度。
- 查错题和补全代码。

答题习惯：
- 代码题先处理空结构。
- 指针变化先画图再写代码。
- 每次 malloc 后考虑是否成功。
- 删除结点时先保存待删指针，再改链，再 free。

## 复杂度

常见复杂度：
- \(O(1)\)：常数操作。
- \(O(\log n)\)：二分查找、平衡树查找。
- \(O(n)\)：顺序扫描。
- \(O(n\log n)\)：归并排序、快速排序平均情况、堆排序。
- \(O(n^2)\)：冒泡、选择、插入排序最坏或平均情况。

分析方法：
1. 找基本操作。
2. 看循环次数。
3. 嵌套循环通常相乘。
4. 顺序结构取最大阶。
5. 递归用递推式。

## 顺序表

特点：
- 随机访问快：按下标访问 \(O(1)\)。
- 插入删除通常要移动元素：\(O(n)\)。

插入思路：
1. 判断位置是否合法。
2. 判断是否满。
3. 从后往前移动元素。
4. 放入新元素。
5. 长度加 1。

C 代码模板：
```c
int ListInsert(int a[], int *length, int capacity, int pos, int value) {
    int i;
    if (pos < 0 || pos > *length) return 0;
    if (*length >= capacity) return 0;
    for (i = *length; i > pos; --i) {
        a[i] = a[i - 1];
    }
    a[pos] = value;
    ++(*length);
    return 1;
}
```

## 单链表

结点定义：
```c
typedef struct Node {
    int data;
    struct Node *next;
} Node;
```

头插法：
```c
void PushFront(Node **head, int value) {
    Node *p = (Node *)malloc(sizeof(Node));
    if (p == NULL) return;
    p->data = value;
    p->next = *head;
    *head = p;
}
```

删除第一个值为 value 的结点：
```c
int DeleteValue(Node **head, int value) {
    Node *cur = *head;
    Node *prev = NULL;
    while (cur != NULL && cur->data != value) {
        prev = cur;
        cur = cur->next;
    }
    if (cur == NULL) return 0;
    if (prev == NULL) {
        *head = cur->next;
    } else {
        prev->next = cur->next;
    }
    free(cur);
    return 1;
}
```

易错点：
- 删除头结点时要修改 head。
- 删除后不能再访问已 free 的结点。
- 遍历条件常写成 `p != NULL`，访问 `p->next` 前要保证 `p` 非空。

## 栈

特点：
- 后进先出。
- 常用于括号匹配、表达式求值、递归模拟、深度优先搜索。

**例：括号匹配** — 判断 `"{[()()]}"` 是否合法。

用栈模拟：
- `{`入栈 → `[`入栈 → `(`入栈 → `)`与栈顶`(`匹配，弹出 → `(`入栈 → `)`匹配弹出 → `]`与`[`匹配弹出 → `}`与`{`匹配弹出
- 栈空 → **合法** ✓

反例：`"[(])"` — `[`入, `(`入, 遇`]`但栈顶是`(`不匹配 → **非法** ✗。

**例：后缀表达式求值** — 求 `"35*2+"`。

- 3入栈 → 5入栈 → `*`：弹出5,3，3×5=15入栈 → 2入栈 → `+`：弹出2,15，15+2=**17**。

顺序栈：
```c
#define MAXSIZE 100

typedef struct {
    int data[MAXSIZE];
    int top;
} Stack;

void InitStack(Stack *s) {
    s->top = -1;
}

int Push(Stack *s, int value) {
    if (s->top == MAXSIZE - 1) return 0;
    s->data[++s->top] = value;
    return 1;
}

int Pop(Stack *s, int *value) {
    if (s->top == -1) return 0;
    *value = s->data[s->top--];
    return 1;
}
```

## 队列

特点：
- 先进先出。
- 常用于广度优先搜索、层次遍历、缓冲区。

循环队列：
```c
#define MAXSIZE 100

typedef struct {
    int data[MAXSIZE];
    int front;
    int rear;
} Queue;

void InitQueue(Queue *q) {
    q->front = q->rear = 0;
}

int IsEmpty(Queue *q) {
    return q->front == q->rear;
}

int IsFull(Queue *q) {
    return (q->rear + 1) % MAXSIZE == q->front;
}

int EnQueue(Queue *q, int value) {
    if (IsFull(q)) return 0;
    q->data[q->rear] = value;
    q->rear = (q->rear + 1) % MAXSIZE;
    return 1;
}

int DeQueue(Queue *q, int *value) {
    if (IsEmpty(q)) return 0;
    *value = q->data[q->front];
    q->front = (q->front + 1) % MAXSIZE;
    return 1;
}
```

记忆：
- 空：`front == rear`。
- 满：`(rear + 1) % MAXSIZE == front`。
- 牺牲一个空间区分空和满。

## 二叉树

结点定义：
```c
typedef struct TreeNode {
    int data;
    struct TreeNode *left;
    struct TreeNode *right;
} TreeNode;
```

遍历：
- 先序：根、左、右。
- 中序：左、根、右。
- 后序：左、右、根。
- 层序：用队列。

递归遍历：
```c
void PreOrder(TreeNode *root) {
    if (root == NULL) return;
    printf("%d ", root->data);
    PreOrder(root->left);
    PreOrder(root->right);
}
```

二叉搜索树：
- 左子树所有值小于根。
- 右子树所有值大于根。
- 中序遍历得到有序序列。

**题目**：依次插入 {50, 30, 80, 20, 40, 70, 90} 构造 BST，画出最终树；然后写出删除 30 后的 BST。

**解（构造）**：

```
50 → 50    →  50     →    50      →    50       →     50        →      50
    /         /  \        /  \         /  \           /  \             /    \
   30        30   80     30   80      30   80        30   80          30     80
                        /            /  \            /  \  / \       /  \   /  \
                       20           20   40        20  40 70 90    20  40 70  90
```

中序遍历：20,30,40,50,70,80,90（有序 ✓）。

**删除 30**（有两个子结点 → 用中序后继 40 替代）：

```
      50                   50
     /    \               /    \
    30     80    →      40     80
   /  \   /  \         /  \   /  \
  20  40 70  90       20 (原40删除) 70 90
```

最终 BST：根 50，左子 40（左 20），右 80（左 70, 右 90）。中序：20,40,50,70,80,90 ✓。

查找：
```c
TreeNode *SearchBST(TreeNode *root, int key) {
    while (root != NULL) {
        if (key == root->data) return root;
        if (key < root->data) root = root->left;
        else root = root->right;
    }
    return NULL;
}
```

## 图

存储结构：
- 邻接矩阵：适合稠密图，判断边是否存在 \(O(1)\)，空间 \(O(n^2)\)。
- 邻接表：适合稀疏图，空间 \(O(n+e)\)。

DFS：
- 用递归或栈。
- 一条路走到底，再回溯。

BFS：
- 用队列。
- 一层一层访问。

DFS 伪代码：
```c
void DFS(Graph *g, int v) {
    visited[v] = 1;
    visit(v);
    for each neighbor w of v:
        if (!visited[w]) DFS(g, w);
}
```

BFS 伪代码：
```c
void BFS(Graph *g, int start) {
    Queue q;
    InitQueue(&q);
    visited[start] = 1;
    EnQueue(&q, start);
    while (!IsEmpty(&q)) {
        int v;
        DeQueue(&q, &v);
        visit(v);
        for each neighbor w of v:
            if (!visited[w]) {
                visited[w] = 1;
                EnQueue(&q, w);
            }
    }
}
```

---

**题目**：给定无向图邻接表：0→[1,2], 1→[0,3,4], 2→[0,4], 3→[1], 4→[1,2]。从顶点 0 出发，写出 DFS 和 BFS 的遍历序列（编号小的优先访问）。

**解（DFS）**：
0→1→3（到底回溯）→4→2。序列：**0,1,3,4,2**。

**解（BFS）**：
0（入队）→ 出 0，邻接 1,2 入队 → 出 1，邻接 3,4 入队 → 出 2，邻接 4 已访问 → 出 3 → 出 4。序列：**0,1,2,3,4**。

**对比**：同一张图，DFS 优先纵向深入，BFS 按层遍历。

## 查找

顺序查找：
- 时间复杂度 \(O(n)\)。
- 对顺序无要求。

二分查找：
- 适用于有序顺序表。
- 时间复杂度 \(O(\log n)\)。

```c
int BinarySearch(int a[], int n, int key) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == key) return mid;
        if (a[mid] < key) left = mid + 1;
        else right = mid - 1;
    }
    return -1;
}
```

哈希表：
- 重点：哈希函数、冲突处理、装填因子。
- 冲突处理：开放定址法、链地址法。

## 排序

稳定排序：
- 冒泡排序。
- 插入排序。
- 归并排序。

不稳定排序：
- 选择排序。
- 快速排序。
- 堆排序。
- 希尔排序通常不稳定。

复杂度速表：

| 排序 | 平均 | 最坏 | 稳定性 |
| --- | --- | --- | --- |
| 冒泡 | \(O(n^2)\) | \(O(n^2)\) | 稳定 |
| 选择 | \(O(n^2)\) | \(O(n^2)\) | 不稳定 |
| 插入 | \(O(n^2)\) | \(O(n^2)\) | 稳定 |
| 希尔 | 依赖增量 | 依赖增量 | 不稳定 |
| 快速 | \(O(n\log n)\) | \(O(n^2)\) | 不稳定 |
| 归并 | \(O(n\log n)\) | \(O(n\log n)\) | 稳定 |
| 堆 | \(O(n\log n)\) | \(O(n\log n)\) | 不稳定 |

**题目 1（快速排序）**：对 {49, 38, 65, 97, 76, 13, 27} 执行一趟划分，pivot=49。

**解**：从右向左找 <49→27，交换到左；从左向右找 >49→65，交换到右。继续直到指针相遇。

第一趟后：{27, 38, 13, 49, 76, 97, 65}。pivot 49 在最终位置（索引 3）。

**题目 2（堆排序建堆）**：将 {4, 10, 3, 5, 1, 7} 建成大根堆，画出建堆过程。

**解**（从最后一个非叶结点开始向下调整，下标从 0 开始）：

初始数组：[4,10,3,5,1,7]。非叶结点：索引 2（值 3）、索引 1（值 10）、索引 0（值 4）。

- 调索引 2（值 3）：子 7>3 → 交换 3↔7 → [4,10,7,5,1,3]
- 调索引 1（值 10）：子 5<10 ✓ → 不变
- 调索引 0（值 4）：子 10>4 → 交换 4↔10 → [10,4,7,5,1,3]；继续调索引 1（值 4）：子 5>4 → 交换 4↔5 → [10,5,7,4,1,3]

大根堆：[10,5,7,4,1,3]。树形：根 10，左 5 右 7，5 的左右为 4,1，7 的左右为 3,—。

## 考前易错点

- 链表插入删除要考虑头结点和空表。
- 循环队列满队条件不是 `rear == front`。
- 二叉树遍历顺序不要混。
- 二叉搜索树中序遍历有序。
- 图的 BFS 用队列，DFS 用递归或栈。
- 快速排序最坏情况可能是 \(O(n^2)\)。
- C 代码中指针传参需要区分 `Node *head` 和 `Node **head`。

## AVL 树（平衡二叉搜索树）

定义：
- AVL 树是高度平衡的二叉搜索树，任意结点的左右子树高度差绝对值不超过 1。
- **平衡因子** = 左子树高度 - 右子树高度，取值仅 \(-1,0,1\)。
- 查找、插入、删除均为 \(O(\log n)\)。

### 四种失衡与旋转

| 失衡类型 | 情况 | 修复方式 |
|----------|------|---------|
| **LL** | 左子树的左子树插入导致失衡 | **右单旋** |
| **RR** | 右子树的右子树插入导致失衡 | **左单旋** |
| **LR** | 左子树的右子树插入导致失衡 | 先左旋左子树，再右旋根 |
| **RL** | 右子树的左子树插入导致失衡 | 先右旋右子树，再左旋根 |

判断方法：
1. 从插入点向上找第一个平衡因子绝对值 > 1 的结点。
2. 看插入路径前两步的方向（如 LL、LR 等）。
3. 执行对应旋转。

LL 右单旋示意图：
```
    A (BF=2)          B (BF=0)
   / \               / \
  B   Ar    →      C    A
 / \                    / \
C   Br                Br  Ar
```

**例**：依次插入 50, 40, 30 构造 AVL 树。

- 插入 50：(50) BF=0
- 插入 40：50 左子 40，(50 BF=1)
- 插入 30：50 BF=2（失衡！），路径 50→40→30，LL型。
- **右单旋**：40 上升为根，50 右旋。最终：(40, 左子 30, 右子 50), 全 BF=0。

**例 LR型**：插入 50, 30, 40。
- 插入 50：(50)
- 插入 30：(50 BF=1, 左 30)
- 插入 40：30 的右子 40。50 BF=2（左深 2），30 BF=-1（右深 1），LR型。
- **先左旋左子树**：30-40 左旋 → 40 升为左子，30 为其左子。
- **再右旋根**：50-40 右旋 → 40 升为根。最终：(40, 左 30, 右 50)。

易错点：
- 旋转后要更新平衡因子。
- 插入一个结点最多导致一次旋转（但删除可能多次）。
- 考试常考手工画旋转过程，不要求完整代码。

## B 树与 B+ 树

### m 阶 B 树的性质

1. 每个结点最多 \(m\) 个子树（最多 \(m-1\) 个关键字）。
2. 根结点至少 2 个子树（除非是叶子）。
3. 非根非叶结点至少 \(\lceil m/2\rceil\) 个子树。
4. 所有叶子结点在同一层。
5. 有 \(k\) 个子树的结点恰好有 \(k-1\) 个关键字。

例：3 阶 B 树（2-3 树）—— 每个结点 1 或 2 个关键字，2 或 3 个子树。

**构造例**：依次插入 {10,20,5,6,12,30,7} 构造 3 阶 B 树。

- 10,20：[10|20] (OK)
- 5：[5|10|20] → 3 关键字，分裂！10 上升。
  ```
     [10]
    /    \
  [5]   [20]
  ```
- 6：[5|6] OK
- 12：[12|20] OK
- 30：[12|20|30] → 分裂！20 上升。
  ```
     [10|20]
    /   |   \
  [5|6] [12] [30]
  ```
- 7：[5|6|7] → 分裂！6 上升。根 [6|10|20] → 再分裂！10 上升。
  ```
        [10]
       /     \
    [6]      [20]
   /   \    /    \
  [5] [7] [12]  [30]
  ```
所有叶结点在同一层 ✓

### B+ 树特点

- 所有关键字冗余存在于叶子结点。
- 非叶子结点仅作索引，不含数据指针。
- 叶子结点通过**链表**串联，支持高效范围查询。
- 典型应用：数据库索引（如 MySQL InnoDB 的主键索引）。

### B 树 vs B+ 树

| 特性 | B 树 | B+ 树 |
|------|------|-------|
| 数据存储 | 内部结点也存数据 | 仅叶子存数据 |
| 范围查询 | 需中序遍历 | 叶子链表直接扫描 |
| 查询稳定性 | 可能中途命中 | 必须到叶子 |
| 典型应用 | 文件系统 | 数据库索引 |

## 哈夫曼树与编码

### 基本概念

- **带权路径长度（WPL）**：\(\sum w_i\cdot l_i\)，\(w_i\) 为叶结点权值，\(l_i\) 为到根路径长度。
- **哈夫曼树**：WPL 最小的二叉树。
- 哈夫曼树没有度为 1 的结点（\(n_1=0\)）。
- \(n_0=n_2+1\) 成立。

### 构造算法（贪心）

1. 将所有权值视为单结点树，放入集合。
2. 选出权值最小的两棵树。
3. 构造新树：新根权值 = 两子树权值之和。
4. 将新树放回集合。
5. 重复 2-4 直到只剩一棵树。

例：权值 {2,3,5,7,9} 构造哈夫曼树并计算 WPL。
- 步骤：(2+3)→5，(5+5)→10，(7+9)→16，(10+16)→26。
- WPL = \(2\times3+3\times3+5\times2+7\times2+9\times2=5\times1+10\times1+16\times?\) ... 核实：叶子 2(层3),3(层3),5(层2),7(层2),9(层2)。
- WPL = \(2\cdot3+3\cdot3+5\cdot2+7\cdot2+9\cdot2=6+9+10+14+18=57\)。

### 哈夫曼编码

- 左分支标记 0，右分支标记 1。
- 从根到叶的路径构成该叶对应符号的编码。
- 哈夫曼编码是**最优前缀编码**（任一编码不是另一编码的前缀）。

考试重点：
- 给定频率表，画出哈夫曼树，写出编码表。
- 计算 WPL 和压缩比。

## 拓扑排序

### 定义

对有向无环图（DAG），将所有顶点排成线性序列，使得若存在弧 \(\langle v_i,v_j\rangle\)，则 \(v_i\) 必在 \(v_j\) 之前。

**例**：给定有向边 A→B, A→C, B→D, C→D, D→E, C→E。求拓扑序列。

入度：A=0, B=1, C=1, D=2, E=2。

| 步骤 | 出队 | 序列 | 减入度影响 |
|:----:|------|------|-----------|
| 1 | A | A | B→0,C→0（入队） |
| 2 | C | A,C | D→1,E→1 |
| 3 | B | A,C,B | D→0（入队） |
| 4 | D | A,C,B,D | E→0（入队） |
| 5 | E | A,C,B,D,E | — |

输出数 5 = 顶点数 5，无回路。序列：A→C→B→D→E（不唯一）。

### 入度表法（核心算法）

1. 计算所有顶点的入度。
2. 入度为 0 的顶点入栈（或入队）。
3. 当栈非空：
   - 弹出顶点并输出。
   - 将该顶点的所有邻接顶点的入度减 1。
   - 若某邻接点入度变为 0，入栈。
4. 若输出顶点数 < 图中顶点总数，则图中有**回路**，不存在拓扑排序。

时间复杂度：\(O(n+e)\)（邻接表）或 \(O(n^2)\)（邻接矩阵）。

### 应用

- AOV 网（Activity On Vertex）：顶点表示活动，弧表示先后关系。
- 拓扑排序给出可行的活动执行顺序。
- 是**关键路径**计算的前提。

## KMP 字符串匹配算法

### 核心思想

朴素匹配失配时，主串指针回溯。KMP 利用已匹配部分的信息，**主串指针不回溯**，只移动模式串指针。

时间复杂度：\(O(m+n)\)（\(m\) 为模式串长，\(n\) 为主串长）。

### Next 数组（考试重点）

`next[j]`：模式串在第 \(j\) 个字符失配时，应跳转到的位置。

手工求法：
1. `next[1] = 0`（模式串下标通常从 1 开始）。
2. 对于 \(j\ge2\)，`next[j]` = 模式串前 \(j-1\) 个字符的**最长相等前后缀长度 + 1**。

例：模式串 `"abaabcac"`（下标从 1 开始）

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|----|----|----|----|----|----|----|----|
| 模式 | a | b | a | a | b | c | a | c |
| next | 0 | 1 | 1 | 2 | 2 | 3 | 1 | 2 |

求法演示（以 j=6 为例）：
- 前 5 个字符："abaab"
- 最长相等前后缀："ab"（前缀"ab"=后缀"ab"，长度 2）
- `next[6] = 2 + 1 = 3`

### Nextval 数组（改进版）

若跳转到的字符与当前失配字符相同，则可继续向前跳转。

规则：
```
if (模式[t[j]] == 模式[j])
    nextval[j] = nextval[t[j]]
else
    nextval[j] = t[j]
```
（其中 \(t[j]\) 是原始的 next 值。）

考试重点：
- 手工计算给定模式串的 next 和 nextval 数组。
- 模拟 KMP 匹配过程（不要求默写完整代码，但要理解流程）。

### 例 1：单链表逆置

写出将单链表原地逆置的 C 代码，并分析时间复杂度。

**代码**：
```c
void Reverse(Node **head) {
    Node *prev = NULL;
    Node *cur = *head;
    Node *next;
    while (cur != NULL) {
        next = cur->next;     // 保存后继
        cur->next = prev;     // 反转指针
        prev = cur;           // 前驱后移
        cur = next;           // 当前后移
    }
    *head = prev;             // 新头是原尾
}
```

**复杂度**：\(O(n)\) 时间，\(O(1)\) 额外空间。

**边界验证**：空链表（`*head==NULL`）→ 循环不执行，`*head=prev=NULL`，正确。单结点 → 循环执行一次，`prev`=原结点，正确。

**考试记忆点**：三指针法——`prev, cur, next`，循环不变式：`prev` 指向已逆置部分的头。

### 例 2：判断完全二叉树

给定一棵二叉树，判断它是否为完全二叉树。

**思路**：层序遍历（BFS）。遇到第一个空结点后，后面所有结点都必须是空。

**伪代码**：
```c
int IsComplete(TreeNode *root) {
    if (root == NULL) return 1;
    Queue q; InitQueue(&q); EnQueue(&q, root);
    int foundNull = 0;
    while (!IsEmpty(&q)) {
        TreeNode *p; DeQueue(&q, &p);
        if (p == NULL) {
            foundNull = 1;
        } else {
            if (foundNull) return 0;  // 前面有空结点但后面又有非空
            EnQueue(&q, p->left);
            EnQueue(&q, p->right);
        }
    }
    return 1;
}
```

**复杂度**：\(O(n)\) 时间，\(O(n)\) 空间（队列）。

### 例 3：求二叉树的深度

递归和非递归两种方法。

**递归**：
```c
int Depth(TreeNode *root) {
    if (root == NULL) return 0;
    int left = Depth(root->left);
    int right = Depth(root->right);
    return (left > right ? left : right) + 1;
}
```

**非递归（层序遍历）**：
```c
int DepthBFS(TreeNode *root) {
    if (root == NULL) return 0;
    Queue q; InitQueue(&q); EnQueue(&q, root);
    int depth = 0;
    while (!IsEmpty(&q)) {
        int size = QueueSize(&q);
        depth++;
        while (size--) {
            TreeNode *p; DeQueue(&q, &p);
            if (p->left) EnQueue(&q, p->left);
            if (p->right) EnQueue(&q, p->right);
        }
    }
    return depth;
}
```

**复杂度**：递归 \(O(n)\) 栈深度最坏 \(O(n)\)；非递归 \(O(n)\) 队列 \(O(n)\)。

## 公式卡片 — 数据结构必背

### 复杂度速记

\[
\begin{aligned}
O(1)&:\text{ 常数（数组下标访问、栈顶操作）}\\
O(\log n)&:\text{ 二分查找、平衡树查找}\\
O(n)&:\text{ 顺序扫描、链表遍历}\\
O(n\log n)&:\text{ 归并排序、快速排序（平均）、堆排序}\\
O(n^2)&:\text{ 冒泡、选择、插入排序（最坏/平均）}\\
O(2^n)&:\text{ 指数级（暴力枚举子集）}
\end{aligned}
\]

### 二叉树性质（必考）

**第 i 层最多结点数**：
\[
2^{i-1}
\]

**深度为 k 最多结点数**：
\[
2^k-1
\]

**叶子结点与度为 2 结点关系**：
\[
n_0=n_2+1
\]

**完全二叉树深度**：
\[
\lfloor\log_2 n\rfloor+1
\]

**n 个结点的二叉树有**：
\[
n-1\text{ 条边}
\]

### 循环队列

**判空**：\(front=rear\)
**判满**：\((rear+1)\bmod MAXSIZE=front\)
**元素个数**：\((rear-front+MAXSIZE)\bmod MAXSIZE\)

### 哈夫曼树

**带权路径长度**：
\[
WPL=\sum_{i=1}^{n}w_i\cdot l_i
\]

**性质**：\(n_1=0\)（无度为 1 的结点），\(n_0=n_2+1\)

**构造**：贪心，每次选两个最小权值合并。

### AVL 树旋转

| 类型 | 失衡路径 | 修复 |
|------|---------|------|
| LL | 左子树的左子树 | 右单旋 |
| RR | 右子树的右子树 | 左单旋 |
| LR | 左子树的右子树 | 先左旋左子树，再右旋根 |
| RL | 右子树的左子树 | 先右旋右子树，再左旋根 |

**平衡因子**：\(BF=\text{左子树高}-\text{右子树高}\in\{-1,0,1\}\)

### B 树（m 阶）

**子结点数范围**：根 \(2\sim m\)，其余 \(\lceil m/2\rceil\sim m\)
**关键字数范围**：根 \(1\sim m-1\)，其余 \(\lceil m/2\rceil-1\sim m-1\)
**所有叶结点在同一层**。

**next 数组**（从 1 开始）：
\[
next[1]=0,\quad next[j]=\text{前 }j-1\text{ 字符的最长相等前后缀长度}+1
\]

**时间复杂度**：
\[
O(m+n)\quad(m\text{ 模式串长}, n\text{ 主串长})
\]

### 图算法复杂度

\[
\begin{aligned}
\text{邻接矩阵}&:O(n^2)\text{ 空间}\\
\text{邻接表}&:O(n+e)\text{ 空间}\\
\text{DFS/BFS}&:O(n+e)\text{（邻接表）或 }O(n^2)\text{（邻接矩阵）}\\
\text{Dijkstra}&:O(n^2)\text{（朴素）或 }O((n+e)\log n)\text{（堆优化）}\\
\text{Prim/Kruskal}&:O(n^2)\ /\ O(e\log e)
\end{aligned}
\]

## 红黑树

### 五条性质

1. 每个结点是红色或黑色
2. 根结点是黑色
3. 每个叶结点（NIL）是黑色
4. 红色结点的两个子结点都是黑色（**无连续红**）
5. 从任意结点到其所有后代叶结点的路径上，黑色结点数相同（**黑高一致**）

### 与 AVL 树对比

| 特性 | AVL 树 | 红黑树 |
|------|--------|--------|
| 平衡条件 | 严格（|BF|≤1） | 宽松（黑高一致） |
| 查找 | 更快（更平衡） | 略慢 |
| 插入删除 | 旋转次数更多 | 旋转 ≤3 次 |
| 应用 | 查找密集场景 | C++ STL map/set, Java TreeMap |

### 插入调整（3 种情况）

插入红结点 → 若父为黑则无问题 → 若父为红则调整：
- Case 1：叔叔红色 → 变色
- Case 2：叔叔黑色 + 三角型 → 旋转
- Case 3：叔叔黑色 + 直线型 → 旋转+变色

考试通常要求画图演示插入过程，不要求完整代码。

## Trie 树（字典树）

### 基本概念

用于字符串集合的高效存储和查找。

- 根结点不存字符
- 每条边代表一个字符
- 从根到某结点的路径构成一个前缀
- 结点可标记 "isEnd" 表示某单词以此结尾

### 时间复杂度

- 查找：\(O(L)\)，\(L\) 为字符串长度（与数据量无关！）
- 插入：\(O(L)\)
- 空间：\(O(\text{字符集大小}\times\sum L)\)

### 典型应用

- 自动补全（autocomplete）
- 拼写检查
- 最长公共前缀
- IP 路由前缀匹配

## 外部排序

### 什么是外部排序

数据量太大无法全部加载到内存，需要借助磁盘。

### 多路归并排序（核心方法）

1. **初始归并段**（run）：每次读入内存能装下的数据，内部排序后写回磁盘
2. **多路归并**：同时归并 \(k\) 个归并段
3. 用**败者树**（loser tree）优化 k 路归并中的最小值选取

### 置换-选择排序

生成**更长的初始归并段**，使段的数量减少，从而减少归并趟数。

## 跳表（Skip List）

### 基本思想

在有序链表上增加多层索引，用空间换时间。

- 第 0 层是原始有序链表
- 第 k 层是第 k-1 层的子集
- 查找时从最高层开始，水平→向下交替移动

### 复杂度

- 查找/插入/删除：平均 \(O(\log n)\)
- 空间：\(O(n)\)（期望）
- 实现比平衡树简单，性能接近

### 应用

Redis 的有序集合（Sorted Set）、LevelDB

## 速记清单（完整版）

- 顺序表：查找快，插删慢。
- 链表：插删方便，不能随机访问。
- 栈：后进先出。
- 队列：先进先出。
- 树：遍历、BST、递归。
- 图：邻接矩阵、邻接表、DFS、BFS。
- 查找：顺序、二分、哈希。
- 排序：复杂度和稳定性。
- **AVL 树**：平衡因子 ±1，四种旋转（LL→右单旋, RR→左单旋, LR, RL）。
- **B 树**：所有叶同层，结点关键字 \(\lceil m/2\rceil-1\) 到 \(m-1\)。
- **哈夫曼树**：WPL 最小、贪心构造、前缀编码。
- **拓扑排序**：入度为 0 入栈、输出、减入度，检测回路。
- **KMP**：next[j] = 前 j-1 个字符最长相等前后缀 + 1。
