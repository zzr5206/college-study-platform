# 错题压缩笔记 — 临考快速翻阅

说明：每题压缩为三行——**错因**、**正确入口**、**关键公式/步骤**。适合考前 30 分钟快速扫一遍。

---

## 复变函数

### 1. 判断解析性只看一点
- **错因**：在某点验证 C-R 方程成立就说在该点解析。
- **入口**：解析 = 在一个**邻域（区域）**内处处可导。仅一点不算。
- **关键**：C-R + 偏导连续 + 邻域。三者缺一不可。

### 2. Cauchy 公式用错阶数
- **错因**：分母是 \((z-z_0)^2\) 却当一阶 Cauchy 公式用。
- **入口**：先看分母次数 → 确定是 n=0（一阶）还是高阶。
- **关键**：\((z-z_0)^{-(n+1)}\) 对应 \(f^{(n)}(z_0)\cdot\frac{2\pi i}{n!}\)。n=1 时乘 \(f'(z_0)\)。

### 3. 留数只取负一次幂
- **错因**：把 Laurent 展开中所有负幂系数求和当留数。
- **入口**：留数 = \((z-z_0)^{-1}\) 的系数 \(c_{-1}\)，仅此一项。
- **关键**：一阶极点留数 = \(\lim(z-z_0)f(z)\)，m 阶 = \(\frac{1}{(m-1)!}\lim\frac{d^{m-1}}{dz^{m-1}}[(z-z_0)^mf(z)]\)。

### 4. 奇点分类混淆
- **错因**：看到分母为零就是极点。
- **入口**：看 Laurent 展开的负幂——无可去、有限极点、无穷本性。
- **关键**：\(\frac{\sin z}{z}\) 在 z=0：展开 \(\frac{z-z^3/6+\cdots}{z}=1-z^2/6+\cdots\) 无负幂 → 可去奇点。

### 5. 实积分三类型选错
- **错因**：乱选积分类型，直接套用公式。
- **入口**：\(\int_0^{2\pi}R(\cos,\sin)\) → z 代换；\(\int_{-\infty}^\infty\frac{P}{Q}\) 无 e^{imx} → 上半平面留数；有 e^{imx} → Jordan 引理。
- **关键**：取上半平面奇点、算留数、乘 \(2\pi i\)。

### 6. 共形映射忘记检验导数不为零
- **错因**：写出 Möbius 变换就完成任务。
- **入口**：共形映射两个条件——单叶解析 + \(f'(z)\ne0\)。Möbius 变换天然满足（ad-bc≠0）。
- **关键**：上半平面→单位圆盘公式：\(w=e^{i\theta}\frac{z-z_0}{z-\overline{z_0}}\)。

## 抽象代数

### 1. 子群和正规子群混为一谈
- **错因**：证了子群就说正规。
- **入口**：子群 + 对共轭封闭 = 正规子群。两者是不同概念。
- **关键**：正规判定：\(\forall g\in G,\ gNg^{-1}\subseteq N\)（或 \(gN=Ng\)）。

### 2. 同态核的证明不完整
- **错因**：只证了 \(\ker\varphi\) 是子群，忘了证正规。
- **入口**：核一定是正规子群。证正规：\(\varphi(gkg^{-1})=\varphi(g)e\varphi(g)^{-1}=e\)。
- **关键**：核的正规性一步就出来，不要写成子群就交卷。

### 3. Lagrange 定理用反方向
- **错因**：以为子群阶整除群阶的逆也成立。
- **入口**：Lagrange 定理只保证 \(|H|\mid|G|\)，不能由 d||G| 推出存在 d 阶子群。
- **关键**：Sylow 定理才是存在性定理。A₄（阶 12）没有 6 阶子群（反例）。

### 4. Sylow 定理 n_p 条件记混
- **错因**：n_p ≡ 1 (mod p) 和 n_p | m 只记一个。
- **入口**：n_p |G| = p^a·m → 必须同时满足两个条件。
- **关键**：n_p ≡ 1(mod p) 且 n_p | m。n_p = 1 ↔ Sylow p-子群正规。

### 5. 理想判断漏乘向
- **错因**：只验证了加法子群，没有验证乘法吸收。
- **入口**：理想需对环中**任意**元素乘法吸收。∀r∈R, a∈I → ra∈I（且 ar∈I）。
- **关键**：\(\mathbb Z\) 中 \(2\mathbb Z\) 是理想，\(\mathbb Z\) 在 \(\mathbb Q\) 中不是理想。

### 6. 整环和域的条件搞反
- **错因**：把 \(\mathbb Z_n\) 是域的条件记成"n 为任意整数"。
- **入口**：域 ↔ 非零元都可逆。\(\mathbb Z_n\) 中 \([a]\) 可逆 ↔ gcd(a,n)=1。
- **关键**：\(\mathbb Z_n\) 是域 ↔ n 是素数。\(\mathbb Z_n\) 是整环 ↔ n 是素数（有限整环即域）。

## 运筹学

### 1. 对偶方向写反
- **错因**：max 转 min 时约束符号方向搞混。
- **入口**：max + ≤ 约束 ↔ min + ≥ 约束。行列互换。
- **关键**：原约束 ≤(max) → 对偶变量 ≥0；原约束 ≥(max) → 对偶变量 ≤0；原约束 =(max) → 对偶变量无限制。

### 2. 单纯形法比值检验只看正数
- **错因**：最小比值检验时用了负的主元列元素。
- **入口**：θ = min{b_i / a_{ik} | a_{ik} > 0}。只除以正的主元列元素。
- **关键**：若某列所有元素 ≤0，则目标函数无界。

### 3. 动态规划漏写边界条件
- **错因**：写了状态转移就结束。
- **入口**：动规五件套——阶段、状态、决策、转移、边界。
- **关键**：边界条件是递推的起点，漏了整道题没分。

### 4. 排队论 ρ 不检查
- **错因**：直接套公式不管 ρ 是否 <1。
- **入口**：ρ = λ/μ（单台）或 ρ = λ/(cμ)（多台）< 1 系统才稳定。
- **关键**：ρ ≥ 1 时队列无限增长，M/M/1 所有公式失效。

### 5. M/M/1 L_s 和 L_q 搞混
- **错因**：L_s 和 L_q 互换计算。
- **入口**：L_s 含正在服务的顾客，L_q 只含排队的。Little：L_s=λW_s, L_q=λW_q。
- **关键**：L_s = ρ/(1-ρ)，L_q = ρ²/(1-ρ)。L_q 比 L_s 多乘一个 ρ。

### 6. EOQ 单位不统一
- **错因**：R 用年、C₁ 用月，直接代公式。
- **入口**：R、C₁、C₃ 的时间单位必须一致（都按年或都按月）。
- **关键**：Q* = √(2C₃R/C₁)，代入前检查单位。

## 数据结构 C 版

### 1. 删除链表结点不改 head
- **错因**：删除头结点时只改了 prev->next，没更新 head。
- **入口**：删头结点 → *head = cur->next。函数需传 Node** 或返回新 head。
- **关键**：删前先判断 cur == *head，单独处理。

### 2. 循环队列满条件写错
- **错因**：写成 (rear == front) 或无脑记成 (rear+1 == front)。
- **入口**：牺牲一个单元后，满 = (rear+1) % MAXSIZE == front。
- **关键**：注意取模！不取模的 rear+1 == front 只在 front=0 时对。

### 3. AVL 旋转后忘更新平衡因子
- **错因**：旋转完树结构就认为完成了。
- **入口**：旋转后必须重新计算受影响结点的平衡因子。
- **关键**：LL 单旋后原根和新根的 BF 都变为 0；LR 双旋后三个结点 BF 需要分别计算。

### 4. KMP next 数组下标混淆
- **错因**：下标从 0 和从 1 开始的 next 数组混用。
- **入口**：确认教材约定——严蔚敏版从 1 开始，next[1]=0。从 0 开始则全部 -1。
- **关键**：next[j] = 前 j-1 个字符最长相等前后缀长度 + 1（从 1 开始时）。

### 5. 哈夫曼树 WPL 只算叶结点
- **错因**：把内部结点的权值也加进去了。
- **入口**：WPL = Σ(叶结点权值 × 该叶到根的路径长度)，只算叶子。
- **关键**：构造过程中内部结点的权值是中间结果，不算入 WPL。

### 6. 拓扑排序不检测回路
- **错因**：输出所有入度为 0 的顶点后没检查输出数量。
- **入口**：若输出顶点数 < 图中顶点总数，则图有回路，不存在拓扑排序。
- **关键**：考试中如果题目给的图可能有环，必须加判断。

### 7. 排序稳定性和复杂度只记一半
- **错因**：知道 O(n²) 的有哪些但忘了稳定性。
- **入口**：稳定排序：冒泡、插入、归并（BIM）。其他基本都不稳定。
- **关键**：快速 O(n log n) 平均但最坏 O(n²)；堆 O(n log n) 但不稳定；归并 O(n log n) 稳定但费空间 O(n)。

### 8. 链表指针修改顺序错误
- **错因**：插入时先改新结点 next，再改前驱 next——方向反了。
- **入口**：插入：新结点 next 指后继 → 前驱 next 指新结点。先保存后继地址再改链。
- **关键**：画指针图再写代码；每行代码只改一个指针。

- 复变：C-R 方程写对了吗？Cauchy 公式 n 数对了吗？留数只取 c_{-1}。

- 运筹：对偶方向对吗？ρ = λ/μ < 1 检查了吗？动规边界写了吗？
- 数据结构：删头结点改了 head 吗？队列满了取了模吗？LR 旋转是双旋不是单旋。
